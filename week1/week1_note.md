| Variable | Meaning | In the code |
|---|---|---|
| `q_mes` | **Measured joint positions**: the joints’ current angles | Obtained from `sim.GetMotorAngles(0)`; units: radians |
| `qd_mes` | **Measured joint velocities**: how fast the joint angles are changing | Obtained from `sim.GetMotorVelocities(0)`; units: radians/second |
| `q_d` | **Desired joint positions**: the angles you want the joints to reach at this time | Generated by `ref.get_values(current_time)`; units: radians |
| `qd_d` | **Desired joint velocities**: how fast you want the joints to move at this time | Also generated by `ref.get_values(current_time)`; units: radians/second |
| `kp` | **Proportional gain**: controls how strongly the controller responds to position error | `1000` in your script |
| `kd` | **Derivative gain**: controls how strongly the controller responds to velocity error | `100` in your script |


| Function | Usage |

The 70 parameters in a describes the 7 robot links

| Term | Dimension |
|---|---|
|Y.shape        | (7*T, 70)|
|tau.shape      | (7*T,)|
|a.shape        | (70,)|
|tau_pred.shape |(7*T,)|


A joint connects bodies and allows movement. A link is a rigid body with mass and inertia. More precisely, this model assigns 10 inertial parameters to each moving link:

| Physical property | Number of parameters |
|---|---:|
| Mass \(m\) | 1 |
| First moments \(mc_x, mc_y, mc_z\), describing the centre of mass together with mass | 3 |
| Independent entries of the symmetric inertia matrix | 6 |
| **Total per link** | **10** |




## 1. `feedback_lin_ctrl(...)`

Calculates motor torques to make the robot follow the desired motion.

```python
tau_cmd = feedback_lin_ctrl(
    dyn_model, q_mes, qd_mes, q_d, qd_d, kp, kd
)
```

- `dyn_model`: robot dynamics model.
- `q_mes`, `qd_mes`: measured joint positions and velocities.
- `q_d`, `qd_d`: desired joint positions and velocities.
- `kp`, `kd`: gains controlling position and velocity correction.
- `tau_cmd`: torque command for each joint.

The controller calculates a correcting acceleration, then converts it into torque while compensating for inertia, motion-dependent forces, and gravity.

## 2. Reorder and save torques

```python
tau_mes_all.append(
    dyn_model.ReoderJoints2PinVec(tau_mes, "vel").copy()
)
```

- `ReoderJoints2PinVec`: puts torques into Pinocchio's joint order so they match the regressor rows.
- `"vel"`: selects velocity-coordinate ordering, which also applies to torque.
- `.copy()`: saves an independent snapshot.
- `.append()`: adds the snapshot to the list.

## 3. `np.vstack`

Stacks *matrices* vertically.

```python
Y = np.vstack(regressor_all)
```

Each time step contributes a matrix of shape `(7, 70)`.

For `T` time steps:

```text
Y.shape = (T * 7, 70)
```

## 4. `np.concatenate`

Joins *arrays* end to end.

```python
tau = np.concatenate(tau_mes_all)
```

Each time step contributes seven torque values.

```text
tau.shape = (T * 7,)
```

The torque order matches the rows of `Y`.

## 5. `np.linalg.pinv`

Calculates the pseudoinverse, used to solve least-squares regression.

```python
a = np.linalg.pinv(Y) @ tau
```

Finds parameters `a` that minimise the squared difference between measured and predicted torques.

```python
tau_pred = Y @ a
```

`@` means matrix multiplication.

What does -1 mean inside reshape?
It means “calculate this dimension automatically.”
Suppose:

```Python
Y.shape = (21, 70)
num_joints = 7
```
Then:
```
Y_grouped = Y.reshape(-1, 7, 70)
```
NumPy calculates the missing dimension:
```
21 × 70 = ? × 7 × 70
        → ? = 3
```
So:
```
Y_grouped.shape  # (3, 7, 70)
```
This is a three-dimensional array:
```
(time steps, joints, feature columns)
```
Imagine it as three matrices, each with seven rows and 70 columns. Thus, your interpretation is correct for each time step:
- Rows: num_joints.
- Columns: Y.shape[1].
- The extra first dimension: number of time steps.
The complete array is a stack of matrices, rather than one two-dimensional matrix.

First, reshape:

```text
(T * 7, 70) → (T, 7, 70)
               time, joint, parameter
```

Then select:

- `:`: all time steps.
- `-1`: last joint.
- `-10:`: last 10 parameter columns, belonging to the final link.

```text
Y_last.shape = (T, 10)
```

In `reshape`, `-1` means NumPy calculates that dimension automatically.

## 7. Select the last joint's torques

```python
tau_last = tau.reshape(-1, num_joints)[:, -1]
```

First, reshape:

```text
(T * 7,) → (T, 7)
            time, joint
```

Then select the last joint at every time step.

```text
tau_last.shape = (T,)
```

Fit the last joint's parameters:

```python
a_last = np.linalg.pinv(Y_last) @ tau_last
```

The result contains 10 parameter estimates, although they may not all be uniquely identifiable.

Some parameter changes produce identical effects on the measured joint torques. The measurements therefore cannot distinguish which link contributed that effect.

The measured torque tells us the combined effect of several links, rather than each link’s contribution separately.
It is like knowing that two objects together weigh 10 kg. They could weigh 4 kg and 6 kg, or 3 kg and 7 kg. Knowing the total does not tell us each weight.
Similarly, different combinations of the robot’s masses and inertias can produce the same joint torques, even when we measure its movement. We therefore cannot tell which combination is the true one.
If the first six links’ parameters are known, we can subtract their effects. The remaining information then allows us to calculate the seventh link’s parameters.

The torque measurements contain no information about this parameter. Its corresponding column in Y is entirely zero. Link 1 rotates around a fixed vertical axis, and its mass parameter alone produces no torque about that axis.
Therefore, the regression fits the torque equally well whether this mass is 0 kg, 2.34 kg, or another value. The pseudoinverse chooses zero because it selects the solution with the smallest **parameter-vector norm**.
So the estimated zero means “this mass cannot be determined from these measurements,” not “the link has no mass.” The supplied model’s actual link 1 mass is 2.34 kg.
